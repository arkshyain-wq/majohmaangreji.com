# Majoh Ma Angreji | Studytime With Arkshya 📖✨

> **ગુજરાતીમાં સમજીએ, અંગ્રેજીમાં બોલીએ!**  
> *Understand in Gujarati. Speak in English.*

An engaging comic-book world helping Gujarat’s primary school children (**Standards 1–5**) discover and speak English through colorful stories, animated characters, and joyful songs.

---

## 🌟 Key Highlights

- **13 Demo Comic Batches (50 Full-Color Pages):**
  - **Act 1: School & Clues** (Batches 01–04) — Masti Nagar School, bicycle greetings, movement verbs, and the "CH" phonics mystery.
  - **Act 2: Town & Nature** (Batches 05–09) — Community helpers, bird songs, monkey mischief, and respectful English terms.
  - **Act 3: Discovery & Finale** (Batches 10–13) — Weather words, national unity, and the final mystery clue.
- **Interactive Dual-Mode Reader:**
  - **Flip View:** High-resolution page-by-page illustrated comic flip with thumbnail jump navigation.
  - **PDF View:** Embedded document reader for classroom reading or offline study.
  - **Mobile Touch-Swipe:** Native touch navigation on tablets and smartphones.
  - **Keyboard Navigation:** Arrow keys (`Left` / `Right`) and `Escape` for rapid page flipping.
- **Fresh, Minimalist & Responsive Design:**
  - Indian Saffron (`#FF6E1A`) & Emerald (`#00B368`) brand accents.
  - Modern typography: *Fredoka*, *Noto Sans Gujarati*, and *Plus Jakarta Sans*.
  - Dark-mode glassmorphism canvas with smooth micro-interactions.
- **Interactive Features:**
  - Friendly Web Audio chime & voice greeting: *"Hello! નમસ્તે!"*.
  - 14-day Launch countdown timer.
  - Early access notification form (WhatsApp / Email).
  - PWA Web App Manifest (`site.webmanifest`).

## 🚀 Running Locally

You can run this project locally with any static web server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js / npx
npx serve .
```

Open your browser and navigate to `http://localhost:8000`.

---

## 🌐 Deploying to GitHub Pages

1. In your GitHub repository, navigate to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Choose the `main` branch and `/ (root)` folder.
4. Click **Save**. Your site will be live at `https://arkshyain-wq.github.io/majohmaangreji.com/`.
